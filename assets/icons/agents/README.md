# Agent brand marks

Agent icons identify the application running in a terminal. Keep them separate
from provider logos: Claude Code uses Claude's starburst, while the Anthropic
provider retains Anthropic's corporate mark.

`claude.svg` is the unmodified monochrome Claude mark from
[LobeHub Icons](https://github.com/lobehub/icons/blob/7d7d0379f18b114a4009dc5cb85a7c375284f31b/packages/static-svg/icons/claude.svg).
This is a catalog asset, not an asset downloaded directly from Anthropic.
