# Phosphor navigation assets

The `list.svg`, `tree-view.svg` and `list-magnifying-glass.svg` sidebar navigation
assets are unmodified official [Phosphor Icons](https://github.com/phosphor-icons/core/tree/main/assets/regular)
Regular assets, distributed under the [MIT license](https://github.com/phosphor-icons/core/blob/main/LICENSE).
They use the same family and weight as the existing regular assets.
Apply color explicitly at each SVG render site.
